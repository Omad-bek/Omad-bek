**[어휘장 Eohwijang](https://github.com/Omad-bek/eohwijang)** · [Live app ↗](https://eohwijang.fyi/)

Korean vocabulary tests demand perfect spelling, and flashcards only check whether you recognise a word. Eohwijang makes you type every word from memory and shows exactly which jamo slipped.

- **Typed recall with jamo-level feedback**: a wrong answer is broken into initial, vowel and final (받침)
- **Spaced repetition**, daily goals, XP and streaks
- **Custom on-screen 두벌식 keyboard** with real jamo composition
- **Anonymous Cloud Sync** across devices with no accounts (Supabase RPC)
- **Offline-first PWA**, deployed to GitHub Pages with GitHub Actions
